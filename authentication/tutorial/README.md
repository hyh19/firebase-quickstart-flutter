# Firebase Authentication Flutter 教程系列

## 概述

本教程系列面向有一定 Flutter 基础的开发者，旨在通过实际项目案例，深入讲解如何在 Flutter 应用中集成 Firebase Authentication。教程将从零开始构建一个完整的认证系统，包括用户注册、登录、邮箱验证、资料管理等核心功能。

通过本教程，你将学会：

- 配置 Firebase 项目和 Flutter 应用
- 使用 Firebase UI Auth 快速构建认证界面
- 实现完整的用户认证流程
- 处理认证状态变化
- 使用 Firebase 模拟器进行本地测试

## 目标读者

- 具备 Flutter 基础知识的开发者
- 希望在应用中集成用户认证系统的开发者
- 对 Firebase 服务感兴趣的开发者

## 先修知识

- Dart 语言基础
- Flutter 开发环境搭建
- 基本的 Flutter Widget 概念

## 项目结构

完成本教程后，你将拥有一个完整的 Flutter Firebase 认证应用，包含以下功能：

- 邮箱/密码注册和登录
- 邮箱验证
- 用户资料更新
- 认证状态监听
- 密码重置功能
- Firebase 模拟器支持

## 环境要求

- Flutter SDK >= 3.0.0
- Dart SDK >= 3.0.0
- Firebase CLI
- Android Studio 或 VS Code（带 Flutter 插件）
